Apache Hive

Created2024-03-04|Updated2024-03-04|ESTR4316
|Post View:

Introductory

Hive is a data warehouse infrastructure built on top of Hadoop for providing data summarization, query, and analysis.

Hive Components

  • Two Main Components

    1. High-level language (HiveQL)
    2. Two execution modes
      • Local: reads/writes to local file system
      • Mapreduce: connects to Hadoop cluster and reads/writes to HDFS

  • Two modes:

    1. Interactive mode: using console
    2. Batch mode: submit a script

  • Physical Layout:

    • Warehouse directory in HDFS
      • E.g., /user/hive/warehouse
    • Tables stored in subdirectories of warehouse
      • Partitions form subdirectories of tables
    • Actual data stored in flat files
      • Control char-delimited text, or SequenceFiles
      • With custom SerDe, can use arbitrary format

Introductory Example

Task: Relational join on the table of word counts from Shakespeare collection and table of word counts from Homer


Data Model

Hive deals with Structured Data, of different types: Tables → Partitions → Buckets

  • Table:
    • Typed columns (int, float, string, boolean)
    • Similar to Tables in RDBMS
    • Each Table is a Unique directory in HDFS
    • Also, list: map (for JSON-like data)
  • Partitions:
    • To determine the distribution of data within a Table
      • For example, range-partition tables by date
    • Each Partition is a sub-directory of the main directory in HDFS
  • Buckets:
    • Partitions can be further divided into Buckets
      • For example, Hash partitions within ranges (useful for sampling, join optimization)
    • Each Bucket is stored as a file in the directory

HiveQL

  • Data Definition Language (DDL)
    • Used to define the structure of your data. It includes commands for creating, altering, and dropping database objects such as tables, views, indexes, etc.
    • e.g. CREATE TABLE, DROP TABLE commands with extensions to define file formats, partitioning and bucketing information
  • Data Manipulation Language (DML)
    • Used to manipulate the data stored within the tables. It includes commands for querying, inserting, updating, and deleting data.
    • Query Statements:
      • SELECT, JOIN, UNION, etc

Data Definition Language

  1. Create table

  2. Print a table and its details information

  3. Others

Data Manipulation Language

  • User Defined Functions (UDF)

    • Perform tasks such as Substr, Trim, etc on data elements

  • User Defined Aggregation Function (UDAF)

    • Perform Operations on Columns, e.g. Sum, Average, Max, Min, …

  • User Defined Table-Generating Functions (UDTF)

    • Output a new table
    • e.g. the Explode function which is similar to FLATTEN() in Pig

  • Custom MapReduce scripts

    • The MR scripts must read rows from standard output
    • Write rows to standard input
